# Kyle Zhou Portfolio

Static GitHub Pages portfolio.

## Doodle Goose

The interactive doodle panel is intentionally frontend-only so the site can be hosted entirely on GitHub Pages.

It uses a canvas animation instead of a backend:

- Draw any loose sketch.
- The browser samples points from your strokes.
- Those points animate into a goose-shaped line drawing.

This keeps the interaction fast, personal, and free.
